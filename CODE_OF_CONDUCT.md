# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, give credit, and keep criticism about the work. Harassment, insults and publishing others' private information are not accepted.

## Reporting

Report unacceptable behaviour privately through [GitHub's report feature](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) or by opening a [private security advisory](https://github.com/rujilabs/motion-patterns/security/advisories/new) marked "conduct". Maintainers will review every report and keep the reporter's identity private.
